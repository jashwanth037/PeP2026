What is AWS S3?

Amazon Simple Storage Service (S3) is a highly scalable, durable, and secure object storage service. It stores virtually unlimited data — from images and videos to entire websites — with 99.999999999% (11 nines) durability. S3 powers millions of applications across the globe.

Object Storage 11 Nines Durability Scalable

Static Website Hosting

Static hosting serves pre-built HTML, CSS, and JavaScript files directly to the browser — no servers or databases needed. This means lightning-fast load times, zero server maintenance, and incredibly low costs. Perfect for portfolios, landing pages, and documentation sites.

No Server Needed Fast Delivery Cost Effective
🌐

Why Cloud Hosting?

Cloud hosting eliminates the need for physical hardware. Your content is distributed across multiple data centers worldwide, ensuring high availability and fault tolerance. With pay-as-you-go pricing, you only pay for what you use — scaling effortlessly from one visitor to millions.

Global CDN High Availability Pay-As-You-Go

About This Project

🚀 A Cloud-Native Showcase

This project demonstrates how to deploy a beautiful, fully-functional static website using Amazon S3's static website hosting feature. It's a single self-contained HTML file — no frameworks, no CDN dependencies, no build step required.

Every visual element you see — the animated gradient background, glassmorphism effects, floating particles, and neon glows — is built with pure CSS and minimal vanilla JavaScript. The goal was to prove that cloud hosting + clean code can produce portfolio-quality results.

Designed and developed as a hands-on exercise in AWS cloud fundamentals, modern CSS techniques, and responsive web design.
