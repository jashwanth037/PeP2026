# Hello AWS 🌍 — Static Website on Amazon S3

A visually stunning, portfolio-quality static website hosted on **Amazon S3**. Built entirely with vanilla HTML, CSS, and minimal JavaScript — zero external dependencies.

## ✨ Features

| Feature | Description |
|---|---|
| 🎨 **Animated Gradient Background** | Smooth purple → blue → teal gradient animation |
| 🪟 **Glassmorphism Cards** | Frosted glass effect using `backdrop-filter: blur()` |
| 🌀 **Floating Orbs & Particles** | Pure CSS particle system with rising dots and glowing orbs |
| 💡 **Neon Glow Effects** | Text-shadow based neon glow on headings |
| 🧭 **Floating Navbar** | Sticky navigation with blur background on scroll |
| 🏷️ **"Live on AWS S3" Badge** | Pulsing badge with green live indicator dot |
| 🎯 **Scroll Reveal Animations** | Elements fade in as they enter viewport (IntersectionObserver) |
| 📱 **Fully Responsive** | Mobile-first design that works on all screen sizes |
| 🎛️ **Custom Scrollbar** | Gradient-styled scrollbar matching the color scheme |
| ✋ **Hover Effects** | Lift + glow on cards and interactive elements |

## 📐 Page Sections

1. **Hero** — Bold "Hello AWS 🌍" heading with shimmering gradient text, subtitle, CTA buttons, and live badge
2. **Features** — 3 glassmorphism cards covering AWS S3, Static Hosting, and Cloud Hosting
3. **About** — Project overview card with tech stack pills
4. **Footer** — Credits, technologies used, and copyright

## 🛠️ Tech Stack

- **HTML5** — Semantic markup and page structure
- **CSS3** — Animations, glassmorphism, gradients, responsive layout
- **Vanilla JavaScript** — Scroll-based navbar, mobile menu toggle, IntersectionObserver reveals
- **AWS S3** — Static website hosting and deployment

> **Zero external dependencies** — no CDN links, no frameworks, no build tools required.

## 🎨 Design Highlights

- **Color Palette**: Dark theme with purple (`#7B2FBE`), blue (`#2563EB`), teal (`#0D9488`), and AWS orange (`#FF9900`) accent
- **Typography**: System font stack (`Segoe UI`, `system-ui`) for fast loading
- **Animations**: CSS keyframes for gradients, particles, and orbs — JS IntersectionObserver for scroll reveals
- **Glass Effect**: `backdrop-filter: blur(16px)` with semi-transparent backgrounds
